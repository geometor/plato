.. py:class:: PassageSpec

   Exact primary-source passage specification within a Platonic dialogue.

   :ivar passage_id: Short stable identifier (e.g., ``"meno-81e-85d"``).
   :ivar dialogue_key: Canonical dialogue slug (``"meno"``, ``"theaetetus"``, ``"republic"``,
                       ``"timaeus"``, ``"parmenides"``, ``"philebus"``, ``"laws"``).
   :ivar dialogue_title_en: English title of the dialogue.
   :ivar dialogue_title_el: Greek title of the dialogue.
   :ivar heading: Scholarly section heading for this passage.
   :ivar stephanus_range: Human-readable Stephanus citation span (e.g., ``"81e–85d"``).
   :ivar start_stephanus: Inclusive starting Burnet ``<milestone unit="section">`` key (lowercase).
   :ivar end_stephanus: Inclusive ending Burnet ``<milestone unit="section">`` key (lowercase).
   :ivar burnet_xml: Filename in ``resources/loci_mathematici/sources/el/``.
   :ivar jowett_txt: Filename in ``resources/loci_mathematici/sources/en/``.
   :ivar jowett_start_line: 1-based start line in ``jowett_txt`` (``0`` when using Republic inline markers).
   :ivar jowett_end_line: 1-based inclusive end line in ``jowett_txt`` (``0`` when using Republic inline markers).
   :ivar republic_start_marker: Optional inline marker in PG #55201 (e.g., ``"509D"``).
   :ivar republic_end_marker: Optional exclusive stop marker in PG #55201 (e.g., ``"BOOK VII"`` or ``"535A"``).
