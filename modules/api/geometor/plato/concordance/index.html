geometor.plato.concordance¶

Stephanus concordance and SHA-256 primary-source manifest for geometor-plato.

Reconciles every plato:* citation across the GEOMETOR canon (euclid, elements, proclus, aristotle, hoenen, and pacioli — 58 repository-level citation entries across 63 apparatus files, 33 distinct normalized citation keys) against canonical Stephanus anchors in the six units of Loci Mathematici et Geometrici, and records cryptographic SHA-256 checksums for all 14 public-domain Burnet (1900–1907) and Jowett (1892) source texts.

class geometor.plato.concordance.ConcordanceEntry¶

Canonical cross-corpus Plato citation mapping to Stephanus anchors.

Variables:

  • cite_key – Exact citation key used in sister repositories (e.g., "plato:meno:76A").

  • repos – Tuple of sister repositories declaring this key.

  • dialogue – Canonical Platonic dialogue title.

  • stephanus_locus – Normalized Stephanus coordinate or span.

  • in_codex – True when staged verbatim in Units I–VI; False for peripheral civic/mimetic passages catalogued in Critical Notes.

  • unit_slug – Target unit folder slug in docsrc/loci_mathematici/ (or nearest note unit).

  • stephanus_anchor – Exact RST target label stephanus-<dialogue>-<sec> (when in_codex).

  • euclid_proclus_context – Mathematical/philosophical locus in Euclid, Proclus, Aristotle, Hoenen, or Pacioli.
