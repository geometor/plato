geometor.plato.compile_codex¶

Deterministic 4-track Book Codex compiler for Mathematical & Geometric Dialogues.

Parses John Burnet’s Oxford Classical Text TEI-XML (tlg0059.*.burnet_oct.xml) and Benjamin Jowett’s 3rd-edition English texts (*_jowett_pg*.txt), aligns Stephanus marginal pagination (.. folio::) and cross-reference anchors (.. _stephanus-…:) across both primary language tracks, wires standalone interactive .euclid-graphic SVG figures (.. picture:: /_static/figures/…), and compiles all companion tracks (-en.rst, -el.rst, -summary.rst, -notes.rst), apparatus pages, and the Book index (docsrc/loci_mathematici/index.rst).

Extract exact Stephanus slice from a Burnet TEI-XML file.

Parameters:

  • xml_path – Path to tlg0059.*.burnet_oct.xml.

  • start_stephanus – Inclusive start Stephanus section (e.g., "75d").

  • end_stephanus – Inclusive end Stephanus section (e.g., "76a").

Returns:

Tuple (paragraphs, milestone_progress) where milestone_progress lists each encountered Stephanus section alongside its normalized [0.0, 1.0] offset within the extracted passage.
