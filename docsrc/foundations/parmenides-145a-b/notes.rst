.. rubric:: Dialectical Mereology & Euclidean Figure · Parmenides 145a–b

I. Mereology and Boundary
-------------------------

In *Parmenides* 145a–b, Plato establishes that containment implies limitation: that which contains is a limit (*peras*). This passage provides the philosophical foundation for Euclidean containment:

- :cite:`Euclid Elements I, Def. 13 <euclid:I.def.13>`: *"A boundary is that which is an extremity of anything."*
- :cite:`Euclid Elements I, Def. 14 <euclid:I.def.13>`: *"A figure is that which is contained by any boundary or boundaries."*
